# 온여정 브랜드 가이드

온여정의 공식 브랜드명은 **온여정**, 영문명은 **OnVoy**다. 브랜드 심벌은 한글 초성 `ㅇㅇㅈ`에 서비스의 핵심 흐름인 **계획 → 준비 → 출발**을 결합한다. Git이 추적하는 `docs/brand/v6`가 승인 원본이며, 앱·웹 배포 자산은 이 원본에서 생성한다.

## 브랜드 이름

| 구분 | 올바른 표기 | 사용 위치 |
| --- | --- | --- |
| 한글 | `온여정` | 국내 사용자 화면, 스토어, 고객 커뮤니케이션 |
| 영문 | `OnVoy` | 영문 화면, 기술 메타데이터, 보조 워드마크 |

`nexvoy`, `NexVoy`, `NEXVOY`는 사용자에게 노출되는 브랜드명으로 사용하지 않는다.

## 심벌 의미

- 첫 `ㅇ`의 시계는 여행 **계획**을 뜻한다.
- 둘째 `ㅇ`의 체크는 **준비 완료**를 뜻한다.
- `ㅈ` 윗획의 종이비행기는 **출발**을 뜻한다.
- 종이비행기는 수평으로 오른쪽을 향하며 윗획 중심선보다 `5px` 위에 배치한다.
- 멀리서는 `ㅇㅇㅈ`이 먼저 읽히고, 가까이서는 기능과 여행의 단서가 보인다.

## 브랜드 컬러

`DESIGN.md`의 색상 토큰을 단일 기준으로 사용한다.

| 역할 | 토큰 | 값 |
| --- | --- | --- |
| 주 브랜드 컬러 | `primary` | `#2563EB` |
| 준비 완료 강조 | `primary-active` | `#1D4ED8` |
| 계획 단계 | `primary-disabled` | `#BFDBFE` |
| Primary 위 요소 | `on-primary` | `#FFFFFF` |

흰색과 Primary의 대비는 약 `5.17:1`이다. Pale과 Primary의 대비는 약 `3.64:1`이며 Pale은 텍스트가 아닌 심벌 단계 표현에만 사용한다.

## 공식 에셋

| 파일 | 목적 |
| --- | --- |
| `app-icon.svg` | 시스템 마스크 안전 여백을 포함한 앱 아이콘 원본 |
| `brand-mark.svg` | 밝은 배경용 기본 마크 |
| `brand-mark-reverse.svg` | Primary 배경용 반전 마크 |
| `brand-mark-mono.svg` | 단색 인쇄·플랫폼 마크 |
| `favicon.svg` | 16–32px 전용 단순 심벌 |
| `wordmark-lockup.svg` | `온여정 / OnVoy` 조합 기준 |
| `construction.svg` | 기하·간격 기준 |
| `brand-system.svg` | 전체 브랜드 시스템 보드 |

PNG 배포본은 `docs/brand/v6/png`에 생성한다.

## 사용 규칙

- 밝은 배경에는 `brand-mark.svg`를 사용한다.
- Primary 배경에는 `brand-mark-reverse.svg`를 사용한다.
- 단색 환경에는 `brand-mark-mono.svg`를 사용한다.
- 심벌 주변에는 최소 `64px`, 즉 외곽 획 한 단위만큼의 여백을 확보한다.
- 전체 심벌은 `64px` 이상에서 사용한다. `32px`에서는 세부 접힘보다 `ㅇㅇㅈ` 실루엣을 우선한다.
- `16px` 파비콘에는 내부 행동 단서를 제거한 `favicon.svg`를 사용한다.
- 일반 앱 아이콘에서 심벌은 1024px 캔버스의 78% 배치 영역 안에 두며, 실제 가로 점유율은 약 68%다.
- Android adaptive foreground는 런처가 전경을 확대하므로 58% 배치 영역을 사용한다.
- 앱 아이콘 원본에 둥근 모서리를 굽지 않는다. Android와 iOS 시스템 마스크가 모서리를 처리한다.
- 스플래시 화면에는 앱 아이콘 사각형 대신 배경에 맞는 기본 또는 반전 마크를 사용한다.

## 금지 사항

- 심벌의 가로세로 비율, 글자 간격 또는 획 굵기를 변경하지 않는다.
- 종이비행기의 방향, 높이 또는 접힘 구조를 임의로 변경하지 않는다.
- 지정되지 않은 그라데이션, 그림자, 테두리 또는 색상을 추가하지 않는다.
- 사진이나 복잡한 배경 위에 대비 확보 없이 배치하지 않는다.
- `ㅇㅇㅈ` 일부만 잘라 독립 아이콘으로 사용하지 않는다.
- 워드마크 글꼴을 임의의 장식 서체로 교체하지 않는다.

## 제작 및 배포

v6 산출물은 다음 명령으로 재생성한다.

```bash
node docs/brand/v6/render-system.js
```

`render-system.js`를 기하와 색상의 단일 원본으로 취급한다. 생성된 SVG와 PNG를 직접 수정하지 않는다. 외부 제작사에 워드마크를 전달할 때는 글자를 벡터 윤곽선으로 변환한 별도 납품본을 만든다.

제품 배포 자산까지 함께 갱신하려면 다음 명령을 사용한다.

```bash
pnpm brand:apply
```

`_workspace`는 Git에서 제외된 시안 작업 영역이다. 승인한 결과물만 `docs/brand`로 승격한다. 플랫폼 자산을 갱신한 뒤 앱 빌드와 실제 기기, 브라우저 탭 및 설치형 웹 앱에서 다시 검증한다.
