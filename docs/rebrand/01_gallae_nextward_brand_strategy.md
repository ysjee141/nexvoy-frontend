## 1. 전략 요약

갈래는 여행의 방향을 함께 고르고, 선택을 실제 일정과 목적지로 이어주는 서비스다. 브랜드는 세 가지 신호를 하나의 시각 언어로 묶는다.

1. `갈래`: 함께 결정하는 자연스러운 질문
2. 경로: 여러 선택이 하나의 여행으로 이어지는 과정
3. 웨이포인트: 다음 목적지와 출발의 설렘

제공된 브랜드 시스템 raster와 별도 제공된 primary logo·app icon raster는 현재 시각 기준이다. 보드 전체와 승인 raster는 원본으로 보관하고, 제품 배포용 SVG는 승인 후보의 path 보정 결과로 관리한다. VTracer는 원본 보드 trace QA에 사용하며, 보드 재현·승인 raster 정합성·제품 벡터를 서로 다른 검수 대상으로 둔다.

## 2. 브랜드 결정

| 구분 | 결정 |
| --- | --- |
| 한국 공식 표시명 | `갈래` |
| 글로벌 공식 표시명 | `Nextward` |
| primary logo | `갈래` + 경로 + 웨이포인트 |
| canonical app icon | Journey Indigo 700 바탕 + 흰색 워드마크 + Departure Coral 경로 |
| UI 핵심 컬러 | Journey Indigo 700 `#3342B3`, Indigo 600 `#4052D2`, Departure Coral `#F8725A` |
| 내부 canonical ID | `nextward` |
| 제작자 | `Oreonix` |

`갈래`는 로고와 제품명으로 사용하고, `Nextward`는 글로벌 시장과 기술적 브랜드 아키텍처에서 사용한다. 한국어 워드마크를 `Gallae`로 음역하지 않는다.

## 3. 서비스 정의

갈래는 친구, 연인과 가족이 함께 장소를 고르고, 일정과 준비물을 만들고, 여행 후 경험을 다음 계획으로 이어가는 여행 서비스다.

```text
발견 → 선택 → 계획 → 준비 → 출발 → 경험 → 기록 → 다음 여행
```

### 초기 고객

- 친구와 자유여행을 준비하는 사람
- 일정과 준비물을 혼자 관리하는 데 피로를 느끼는 사람
- 메신저, 지도, 메모를 오가며 계획하는 사람
- 다녀온 여행의 경험을 다음 여행에 다시 쓰고 싶은 사람

### 포지셔닝

갈래는 단순 일정표가 아니라, 함께 선택한 방향이 실제 여행으로 이어지는 과정을 정리하는 서비스다. 협업은 관리 기능이 아니라 여행을 시작하게 하는 감정적 진입점이다.

## 4. 브랜드 성격

갈래는 먼저 답을 정해주는 전문가보다, 함께 후보를 펼쳐보고 자연스럽게 다음 선택을 돕는 친구에 가깝다.

| 성격 | 표현 |
| --- | --- |
| 따뜻함 | 친구에게 제안하듯 말한다 |
| 명료함 | 장소·일정·준비 정보는 짧고 정확하게 보여준다 |
| 설렘 | Coral은 출발과 목적지의 순간에 집중한다 |
| 유연함 | 아직 정하지 않은 상태도 자연스럽게 인정한다 |
| 함께함 | 동행자의 의견과 작은 참여를 연결한다 |

## 6. 로고 전략

### Primary logo

primary logo는 글자와 경로가 분리된 장식이 아니라 하나의 읽히는 브랜드 락업이다. 글자는 라운드 끝처리로 친근함을 만들고, 수평·수직 골격으로 읽기 쉬움을 유지한다.

### Variations

- **Vertical lockup**: 브랜드 소개, 프로필, 좁은 세로 공간
- **Horizontal lockup**: 헤더, 스토어 설명, 넓은 가로 공간
- **Symbol only**: 워드마크를 넣기 어려운 보조 영역
- **App icon variants**: 배경 대비와 캠페인 맥락에 따른 제한된 파생

임의의 질문 부호, 지도 핀, 비행기, 캐리어를 추가하지 않는다. 웨이포인트는 이미 목적지와 방향성을 담당한다.

## 7. 앱 아이콘 전략

canonical dark icon은 작은 화면에서 `갈래`를 직접 읽히게 하는 방향을 택한다. 앱 이름 자체가 식별 자산이므로 별도 심벌을 얹어 의미를 복잡하게 만들지 않는다.

- Journey Indigo 700은 안정감과 방향성을 만든다.
- 흰색 워드마크는 작은 크기에서도 브랜드명을 우선 전달한다.
- Coral 경로는 선택과 출발의 감정을 전달한다.
- app icon의 rounded tile은 reference에 포함된 형태를 보존하되, OS mask와 중복 적용하지 않는다.

## 9. 타이포그래피와 이미지

로고는 폰트가 아니라 승인된 path asset이다. UI는 다음 시스템 스택을 사용한다.

```css
font-family: Pretendard, "Noto Sans KR", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

실제 앱에 Pretendard를 번들하지 않는 환경에서는 시스템 폴백을 사용한다. 여기어때 잘난체, 하이커체, 카페24 써라운드, 주아체, 리아체와 둥근바람은 감성 참고일 뿐 그대로 차용하지 않는다.

승인 SVG는 사용자가 제공한 구조와 형태를 보존하되, 제품 적용에서는 Journey Indigo 700 `#3342B3`, Indigo 600 `#4052D2`, Departure Coral `#F8725A`로 색상을 정규화한다. 원본 raster는 색상 비교가 아닌 형태·구조 검수용으로 보관한다.

사진은 실제 장소와 함께 계획하는 행동이 보이는 이미지를 우선한다. 지나치게 어둡거나 추상적인 이미지로 로고와 장소의 식별성을 희생하지 않는다.

## 10. 성공 기준

- 제공된 raster board와 primary logo의 구조가 오버레이에서 일치한다.
- primary logo, lockup, symbol과 app icon이 같은 Journey Indigo·Departure Coral 언어를 공유한다.
- 앱 아이콘이 16px에서도 `갈래`와 Coral 경로를 식별 가능하게 유지한다.
- `갈래`가 `갈태`로 읽히지 않으며, 글자 끝은 둥글고 골격은 반듯하다.
- 제품 UI는 로고와 일관된 형태·색상을 사용하지만 로고를 폰트로 재조판하지 않는다.
- 레거시 `온여정 / OnVoy` 자산은 신규 사용자 노출에 사용하지 않는다.
